How to use this portal

  1. Start with the exam guide to see the skills outline and how each skill maps to a page.
  2. Work through the pages in order. Use the knowledge checks and the drag & drop exercises on each page, and mark the page as studied at the bottom.
  3. Use the glossary flashcards to drill terminology.
  4. Use practice questions per topic, then run timed exam simulations until you score above 80% consistently.

Your progress is stored only in this browser (local storage). Nothing is sent anywhere.
